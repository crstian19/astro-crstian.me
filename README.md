# crstian.me

My personal website built with Astro, Tailwind CSS, and TypeScript. Features a minimalist design with animated backgrounds and smooth transitions.

## 🚀 Features

- ⚡️ Lightning fast performance
- 🌓 Light/Dark mode with smooth transitions
- 🎨 Animated backgrounds (particles for light mode, stars for dark mode)
- 📱 Fully responsive design
- 🔍 SEO optimized
- 🎯 TypeScript for type safety
- 🎨 Tailwind CSS for styling

## 🛠️ Tech Stack

- [Astro](https://astro.build) - Static site generator
- [Tailwind CSS](https://tailwindcss.com) - CSS framework
- [TypeScript](https://www.typescriptlang.org) - Type safety
- [Vercel](https://vercel.com) - Hosting platform
